ENEMIES PACK v6 (current-directory)
----------------------------------
Three low-poly realistic enemies:
- enemy_fighter.obj/.mtl + enemy_fighter_diffuse.png
- enemy_interceptor.obj/.mtl + enemy_interceptor_diffuse.png
- enemy_bomber.obj/.mtl + enemy_bomber_diffuse.png

Game file:
- space_shooter_models_v6_multi.py (loads the 3 variants automatically)

Usage:
- Put all files in the same folder.
- Optional: add skybox_px.png..skybox_nz.png to enable the cubemap skybox.
- Run: python space_shooter_models_v6_multi.py
